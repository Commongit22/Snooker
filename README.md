# 🎱 Snooker — 斯诺克小游戏（计算机图形学课程作业）

单文件 HTML 小游戏：**双击 `index.html` 打开即玩**，无需联网、无任何依赖。

## ✨ 功能特性

- **完整斯诺克规则（适度简化）**
  - 红球（15 颗 × 1 分）与彩球（黄 2 / 绿 3 / 棕 4 / 蓝 5 / 粉 6 / 黑 7）红彩交替击打
  - 打彩球前需点击指定目标球；红球未清完时彩球自动复位
  - 清台后按 黄→绿→棕→蓝→粉→黑 顺序击打；平分时黑球复位决胜（犯规立即判负）
  - 犯规系统：母球落袋 / 未击中任何球 / 先碰非目标球 / 误进非目标球，罚分 = max(4, 相关球分值)
  - **自由球**：犯规后被斯诺克（几何遮挡检测）时，可点击任意球指定为自由球
  - 双人对战、单杆（连续得分）统计、剩余红球/彩球实时显示
- **真实物理轨迹**
  - 240Hz 固定时间步长积分；滑动摩擦 → 滚动摩擦自然过渡（接触点相对速度模型）
  - 摩擦系数按游戏手感标定：球被击出后数秒内自然停止；接触点滑移小于单步可消减量时直接转入纯滚动（消除固定步长在滑动/滚动临界点的数值极限环），另有 20 秒超时保险强制结算，**保证任何击球后回合必然结束、必然轮到下一人**
  - **高杆**（上旋跟进）/ **中杆**（定杆）/ **低杆**（缩杆）：旋转与平动耦合，真实影响母球碰撞后走向
  - **左塞/右塞**（侧旋）：吃库后反弹角度偏移
  - 等质量动量守恒球-球碰撞、库边反弹（恢复系数 0.72）、袋口入袋判定
  - 瞄准线 + 幽灵球 + 目标球走向/母球分离方向预测
- **光影渲染**
  - 吊灯：黄铜金属灯罩（横向金属渐变 + 纵向明暗）、暗色透视罩口、灯泡强光、模糊软边光束（screen 混合）+ 环境光晕
  - 台面透视椭圆光斑、球体径向渐变着色（主高光 / 次高光 / 暗部）、球下软阴影
  - 台呢纹理、库边暗角、木框渐变高光、球台落影
  - 静态场景（房间/球台/吊灯）离屏画布预渲染，每帧仅一次 drawImage，手机低功耗流畅
- **UI**：规则介绍弹窗、比分/单杆面板、杆法与塞选择、力度条、犯规与自由球提示横幅
- **📱 手机 / 平板可玩**：触屏任意处拖动瞄准、按住母球拖动蓄力松开击球、轻点指定彩球/自由球；响应式布局 + 竖屏横屏游玩提示

## 🎮 操作

| 操作 | 方式 |
| --- | --- |
| 瞄准 | 移动鼠标（带轨迹预测） |
| 击球 | 按住母球向后拖动蓄力，松开击球 |
| 触屏瞄准 / 击球 | 台面任意处拖动瞄准；按住母球拖动蓄力后松开击球 |
| 放置母球 | 开球 / 母球落袋后，在 D 区移动鼠标、点击放置 |
| 指定彩球 | 轮到打彩球时，点击桌上的一颗彩球 |
| 指定自由球 | 出现提示时，点击任意一颗球 |
| 选择杆法 | 右侧面板：高杆 / 中杆 / 低杆 + 左塞 / 右塞 |

## 🛠 技术要点

- 原生 HTML5 Canvas 2D + JavaScript，单文件无第三方库
- 物理：接触点相对速度 `v_contact = v + ω × r` 判定滑动/滚动，摩擦与旋转耦合积分；滑移 < `3.5·μ·Δt` 时截断转入纯滚动，避免固定步长积分在临界点过冲形成周期 2 极限环（球永不停）
- 渲染：径向渐变模拟球面光照，多层高光 + 软阴影模拟台呢散射光
