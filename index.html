📖 斯诺克规则介绍

一、基本规则

  • 15 颗红球各 1 分；彩球：黄 2、绿 3、棕 4、蓝 5、粉 6、黑 7 分。
  • 击球顺序：红球 → 彩球 → 红球 → 彩球……交替进行。
  • 打进红球 +1 分，随后必须打彩球（先点击桌上彩球指定目标）。
  • 打进彩球加对应分值；红球未清完时，彩球放回原位（复位）。
  • 红球清台后，按 黄→绿→棕→蓝→粉→黑 顺序打彩球，打进不再复位。
  • 全部打完分数高者获胜；平分则黑球复位决胜：打进黑球者胜，该阶段犯规立即判负。
  • 「单杆」为本次上手连续得分，失误或犯规即中断。

二、杆法（发球/击球方式）

  • 高杆（上旋）：击球点高于球心，母球撞击目标球后继续向前跟进。
  • 中杆（定杆）：击球点在球心，正面撞击后母球定在原地。
  • 低杆（下旋/缩杆）：击球点低于球心，撞击后母球向回拉。
  • 左塞 / 右塞（侧旋）：母球吃库（碰库边）后反弹角度发生偏移。

三、自由球

  • 犯规后，若对手被斯诺克（母球被非目标球挡住，无法直线打到目标球两侧最边缘），对手可将任意一颗球指定为自由球，按目标球分值计分。
  • 自由球打进后复位，之后按正常规则继续。系统会自动检测并在提示横幅中给出自由球指定机会。

  • 犯规时打进的彩球放回原位，红球不再放回。

五、操作说明

  • 瞄准：移动鼠标（瞄准线带幽灵球与走向预测）。
  • 击球：按住母球向后拖动蓄力（力度 = 拖动距离），松开击球。
  • 触屏（手机 / 平板）：在台面任意处拖动瞄准；按住母球拖动蓄力后松开击球；轻点即点击。
  • 开球 / 母球落袋后：在 D 区内移动鼠标定位母球，点击放置。
  • 指定彩球：轮到打彩球时，点击桌上的一颗彩球。
  • 自由球：出现提示时，点击任意一颗球指定。

六、技术说明（光影与物理）

  • 光影：顶部吊灯（金属灯罩 / 灯泡强光 / 软边光束）、台面透视光斑、球体径向渐变着色（主高光 / 次高光 / 暗部）、球下软阴影、台呢纹理与暗角、木框渐变高光；静态场景离屏预渲染。
  • 物理：240Hz 固定步长积分；滑动摩擦 → 滚动摩擦自然过渡（接触点相对速度模型，摩擦系数按游戏手感标定，球可在数秒内自然停止）；旋转与平动耦合（上/下旋真实影响母球碰撞后走向）；等质量动量守恒碰撞；库边反弹（恢复系数 0.72）与侧旋吃库；袋口判定。
  • 简化：未实现 Miss 规则（未尽力解球重摆）、贴球、跳球等高级规则。
